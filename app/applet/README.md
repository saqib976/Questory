# Questory — Saqib's Video Editing Portfolio

High-retention video editing and motion graphics portfolio for **Saqib** (Questory), engineered for YouTube documentaries and high-velocity vertical reels.

## 🚀 Features
- **YouTube Long-Form Showcase:** Real interactive portfolio featuring top YouTube documentary projects with 4K cinema player and case studies.
- **3D Vertical Reels & Shorts:** Interactive smartphone player for high-velocity vertical shorts and reels.
- **Client Link Auto-Routing:** Dedicated links (`?type=long#portfolio-section` and `?type=shorts#portfolio-section`) with 1-click clipboard sharing.
- **Verified Client Reviews:** Interactive marquee and social proof ratings.
- **Direct Hire / Inquiry Modal:** Instant booking and project estimation form.

## 🛠️ Tech Stack
- React 19 + TypeScript
- Vite
- Tailwind CSS
- Lucide React

## 📦 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Locally in Development
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Build for Production
```bash
npm run build
```
The output will be in the `dist` folder ready to deploy on Vercel, Netlify, Cloudflare Pages, or GitHub Pages.
